💡 Tips & Strategi

Tips bermain OPBR dari pemula hingga advanced

🎯 Tips Attacker

  • Fokus target lemah element
  • Gunakan skill cooldown tepat
  • Jangan agresif tanpa support
  • Medal set fokus damage
  • Timing skill 2 untuk finish

🛡️ Tips Defender

  • Jaga treasure area selalu aman
  • Gunakan hyper armor blocking
  • Partner dengan attacker
  • Medal set fokus HP + defense
  • Jangan kejar runner

🏃 Tips Runner

  • Capture treasure secepat mungkin
  • Speed boost untuk escape
  • Timing capture saat lawan sibuk
  • Medal set fokus speed
  • Jangan fight, fokus capture

📊 Tips Support

  • Build support 160%+ max bonus
  • Sesuaikan element dengan main char
  • Max level semua support
  • Transfer boost semua slot
  • Fokus tag sesuai class main

🏅 Tips Medal

  • 3 medal dengan tag sama
  • Prioritaskan skill CD reduction
  • Medal EX untuk bonus tinggi
  • Upgrade medal ke max
  • Kombinasikan sesuai playstyle

⚡ Tips General

  • Kenali element lawan dulu
  • Timing dodge hindari skill
  • Communication tim penting
  • Fokus objective, bukan kill
  • Practice di solo battle dulu
