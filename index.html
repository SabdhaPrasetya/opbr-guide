💡 Tips & Strategi

Tips bermain OPBR untuk pemula hingga advanced

🎯 Tips Attacker

  • Fokus target yang lemah secara element
  • Gunakan skill cooldown yang tepat
  • Jangan terlalu agresif tanpa support
  • Pilih medal set yang meningkatkan damage
  • Timing skill 2 untuk finishing blow

🛡️ Tips Defender

  • Jaga treasure area selalu aman
  • Gunakan hyper armor untuk blocking
  • Patner dengan attacker untuk defense
  • Medal set fokus defense + HP
  • Jangan kejar runner, fokus defense

🏃 Tips Runner

  • Capture treasure secepat mungkin
  • Gunakan speed boost untuk escape
  • Timing untuk capture saat lawan sibuk
  • Medal set fokus speed + cooldown
  • Jangan fight, fokus capture

📊 Tips Support

  • Build support 160%+ untuk bonus maksimal
  • Gunakan karakter support yang sesuai element
  • Max level semua support karakter
  • Gunakan transfer boost untuk semua slot
  • Fokus tag yang sesuai dengan class main

🏅 Tips Medal

  • Gunakan 3 medal dengan tag yang sama
  • Prioritaskan skill cooldown reduction
  • Medal EX untuk bonus stats lebih tinggi
  • Upgrade medal ke max untuk bonus optimal
  • Kombinasikan medal sesuai playstyle

⚡ Tips General

  • Kenali element lawan sebelum fight
  • Timing dodge untuk hindari skill
  • Communication dengan tim sangat penting
  • Fokus objective, bukan kill
  • Practice di solo battle dulu
